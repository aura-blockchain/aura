# Tutorials

Practical step-by-step guides for common Aura blockchain tasks.

## Getting Started

- [Create a DID](./create-did) - Set up your decentralized identifier
- [Issue a Credential](./issue-credential) - Issue W3C Verifiable Credentials
- [Stake Tokens](./stake-tokens) - Delegate AURA to validators
- [Governance Voting](./governance) - Submit proposals and vote
- [DEX Trading](./dex-trading) - Swap tokens on the DEX

## Prerequisites

All tutorials assume you have:
1. [Installed Aura](/docs/getting-started/installation)
2. A funded wallet (use [testnet faucet](https://faucet.aura.network) for testing)
3. Basic command-line familiarity

## Difficulty Levels

- **Beginner**: No prior blockchain experience required
- **Intermediate**: Familiarity with blockchain concepts
- **Advanced**: Developer experience recommended

TYPICAL WORKFLOW
=====================================

Development (Single Node):
--------------------------
1. aurad quickstart --validator-name dev
   └─> Follow printed instructions

Production (Multi-Node):
-----------------------
1. aurad init mynode --chain-id aura-1
2. aurad keys add validator
3. aurad genesis add-genesis-account validator 100000000stake
4. aurad genesis gentx validator 100000000stake --chain-id aura-1
5. aurad genesis collect-gentxs
6. aurad genesis validate-genesis
7. aurad start

Adding More Accounts:
--------------------
1. aurad keys add alice
2. aurad genesis add-genesis-account alice 50000000stake

Multi-Validator Setup:
---------------------
Node 1:
  aurad genesis gentx validator1 100000000stake --chain-id aura-1
Node 2:
  aurad genesis gentx validator2 100000000stake --chain-id aura-1
Node 1:
  (copy all gentx files to config/gentx/)
  aurad genesis collect-gentxs
  (distribute genesis.json to all nodes)

Vesting Account:
---------------
aurad genesis add-genesis-account alice 100000000stake \
  --vesting-amount 50000000stake \
  --vesting-end-time 1735689600

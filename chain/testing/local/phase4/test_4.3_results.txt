Step 2: Double-Sign Detection Mechanism
========================================

How Tendermint Detects Double-Signing:
1. Each validator signs blocks with their private key
2. If a validator signs TWO different blocks at same height/round
3. Any honest node that sees both signatures can create Evidence
4. Evidence is submitted to the blockchain
5. Slashing module processes the evidence and jails the validator

Creating actual double-sign evidence requires:
1. Access to validator's private key
2. Manually signing two conflicting blocks
3. Broadcasting both signatures to the network

This is intentionally difficult and requires low-level manipulation.
In production, double-signing typically happens due to:
- Misconfigured validator backup systems
- Accidental running of two validator instances with same key
- Malicious validator behavior

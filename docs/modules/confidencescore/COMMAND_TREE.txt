Arena Types:
────────────
• Biometric      - Biometric verification (fingerprint, face, iris)
• Possession     - Device/credential possession
• Knowledge      - Knowledge-based verification
• Social         - Social graph verification
• GeoLocation    - Location-based verification
• HighAssurance  - High-assurance verification methods
• Persistence    - Time-persistence verification
• Specialized    - Specialized verification methods

Score Multipliers:
─────────────────
Velocity Bonus (VBT):
  • Within 7 days:  1.25x ⚡
  • Within 30 days: 1.10x ⚡
  • Otherwise:      1.00x

Arena Multiplier:
  • >= 5000 CS:     1.50x 🎯 (Focus Bonus Active)
  • >= 4000 CS:     1.20x 🎯
  • >= 3000 CS:     1.10x 🎯
  • Otherwise:      1.00x

Jackpot Bonus:
  • 1 in 1000:      25.0x 🎰 (Super Rare!)
  • 1 in 100:       5.00x 🎰 (Rare!)
  • Otherwise:      1.00x

Verification Thresholds:
───────────────────────
• Verified Human:  10,000 CS ✓
• High Assurance:  15,000 CS ✓✓
• Arena Focus:      5,000 CS per arena 🎯

Rate Limits:
───────────
• Max IRs per day:   10 (configurable)
• Max IRs per hour:   3 (configurable)

Appeal Process:
──────────────
1. User receives slash
2. User has 30 days to appeal
3. User submits appeal with deposit (1000 AEQ)
4. Governance reviews evidence
5. If approved: Score restored + deposit returned
6. If denied: Slash stands + deposit forfeit

Common Workflows:
────────────────

New User:
  1. Complete IR-000 (anchor)
  2. Check score: query confidencescore score
  3. Complete more IRs
  4. Monitor progress: query confidencescore history
  5. Reach 10,000 CS → Verified Human! ✓

AI Assistant:
  1. Verify user's IR completion offline
  2. Generate proof hash (SHA256)
  3. Record: tx confidencescore record-completion
  4. Verify: query confidencescore ir-completion

Governance:
  1. Detect fraud
  2. Slash: tx confidencescore slash
  3. If appealed: Review evidence
  4. Resolve: tx confidencescore resolve-appeal

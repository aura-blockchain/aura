# Testnet Feedback

Use GitHub Issues for bugs and GitHub Discussions for general feedback. Keep reports short and specific.

## Bug reports

Include:

- Chain ID and node type (validator/full node/light)
- `aurad version`
- Steps to reproduce
- Expected vs actual behavior
- Logs or error output (redact secrets)

## Feature and UX feedback

Include:

- What you were trying to do
- Where the workflow was unclear
- A concrete suggestion

## Labels and triage owners

Suggested labels:

- `testnet-bug`
- `testnet-ops`
- `testnet-ux`
- `wallet`
- `explorer`
- `faucet`
- `ibc`

Suggested triage owners:

- Node/ops: core chain maintainers
- Wallets: wallet maintainers
- Explorer/faucet: service maintainers

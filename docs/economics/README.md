# Economics & Incentives

Models, spreadsheets, and dashboards covering AEQ emissions, PoI reward multipliers, assistant compensation, and treasury projections.

- `models/` – deterministic spreadsheets or Jupyter notebooks (see `emissions-schedule.*`, `poi-multiplier-scenarios.*`).
- `dashboards/` – Grafana/Metabase configs for live monitoring.
- `reports/` – periodic summaries for governance.

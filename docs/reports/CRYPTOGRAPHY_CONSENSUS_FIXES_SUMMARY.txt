--------------------------------------------------------------------------------
CONSENSUS SAFETY EXPLANATION
--------------------------------------------------------------------------------

PROBLEM:
  time.Now() returns the current wall-clock time, which is different on each
  validator node. This causes:
  - Different IDs generated for the same operation
  - Different expiration check results
  - State divergence between validators
  - Consensus failures and chain halts

SOLUTION:
  sdk.UnwrapSDKContext(ctx).BlockTime() returns the consensus-agreed timestamp
  for the current block. All validators agree on this timestamp, ensuring:
  - Identical IDs across all validators
  - Consistent expiration logic
  - Deterministic state transitions
  - Consensus maintained

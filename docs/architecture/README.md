# Architecture

Store diagrams, sequence flows, and state machines referenced by RFCs.

- `flows/` – SVG/PlantUML diagrams for IR completion, VC issuance, verifier queries, governance votes, assistant slashing.
- `models/` – State machine descriptions and protobuf schemas once finalized.

Diagram sources should be committed (e.g., `.drawio`, `.puml`) alongside exported images.

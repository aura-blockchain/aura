PROBLEM
================================================================================

time.Now() usage in keeper initialization causes non-deterministic state across
validators, leading to consensus failures and chain halts.

Location: chain/x/economicsecurity/keeper/keeper.go:76

================================================================================
SOLUTION
================================================================================

1. KEEPER INITIALIZATION (keeper/keeper.go:76)
   
   BEFORE: currentTime: time.Now().Unix(),
   AFTER:  currentTime: 0,  // Set via BeginBlock with deterministic time
   
2. MODULE BEGINBLOCK (module.go)
   
   BEFORE: func (m AppModule) BeginBlock(height uint64)
   AFTER:  func (m AppModule) BeginBlock(ctx context.Context)
   
   Added:
   - sdkCtx := sdk.UnwrapSDKContext(ctx)
   - height := uint64(sdkCtx.BlockHeight())
   - blockTime := sdkCtx.BlockTime().Unix()
   - m.keeper.SetCurrentTime(blockTime)
